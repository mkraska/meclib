# Text snippets

Text building blocks for the "Snippet ..." button on the Questions page of the
workbench. One file per snippet; the file name (without the leading number and
`.txt`) is the name in the list, the number sets the order. The text is
inserted at the cursor of the editor field last used (question text by
default). Add, change or remove files as needed.

The interactive [[jsxgraph]] snippet needs the inputs `objects` and `names`
(as in the question template); the fixed one needs none.
