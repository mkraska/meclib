JSON list of meclib objects, i.e. what stackjson_stringify(initdata) produces. A leading initdata: and a trailing ; or $ are ignored, so a constant Maxima list can be pasted as is.

Save as test case

Saves the current graphic as a case: its state (the current objects if you have interacted with the graphic, otherwise the start state, if any) is rendered once more, and the resulting objects and names are stored as the expected result. All cases of a scene share the same initdata, decimal separator and [[jsxgraph]] block. The case id is how Maxima tests refer to the case: scene_obj("scene", "id"), scene_names("scene", "id").
